# Data Cleaning & Power Query Documentation

## Preparation workflow

### 1. Inspect source tables
Reviewed the structure, fields and data types of the source Olist tables.

### 2. Check data types
Ensured dates, numbers, text and identifiers were assigned appropriate types.

### 3. Review missing values
Checked missing values, with particular attention to delivery-date fields.

### 4. Standardise fields
Cleaned and standardised fields needed for analysis.

### 5. Merge related tables
Used Power Query merges to bring relevant customer, order, product and seller information together.

### 6. Create analytical fields
Created fields required for delivery and performance analysis.

### 7. Validate the final dataset
Reviewed the merged output before loading it into Power BI.

### 8. Load into Power BI
Loaded the prepared data into the analytical model for DAX calculations and dashboard development.
