# Project Case Study

## 1. Problem

E-commerce businesses need to understand where revenue is generated, how orders move through the fulfilment process, how delivery performs and which products and sellers contribute most to revenue.

## 2. Approach

The analysis followed this workflow:

1. Inspect the source tables.
2. Clean and standardise the data.
3. Review missing values and data types.
4. Merge related tables using Power Query.
5. Prepare the analytical model.
6. Create DAX measures.
7. Build KPI cards and analytical visuals.
8. Add slicers for interactive analysis.
9. Interpret the findings.
10. Develop business recommendations.

## 3. Analytical Questions

The dashboard focuses on:

- Revenue by customer state
- Order-status distribution
- Freight value versus product/order value
- Product-category revenue
- Monthly revenue trend
- Seller revenue
- Delivery and freight KPIs

## 4. Dashboard KPIs

- Total Revenue: R$13.59M
- Total Orders: 99K
- Average Delivery Days: 12
- Average Freight: R$20

## 5. Key Findings

- São Paulo generated approximately R$5.2M, about 38% of displayed total revenue.
- 97.78% of orders were delivered.
- May was the highest monthly revenue point at approximately R$1.5M.
- Beauty & Health was the leading category at approximately R$1.26M.
- The leading seller shown generated approximately R$229K.
- Freight and product/order values are heavily clustered toward lower values in the scatter plot.

## 6. Business Value

The dashboard provides a compact management view of sales, delivery and shipping performance. It allows users to filter by order status, customer state and product category and investigate performance from different perspectives.

## 7. Portfolio Value

This project demonstrates the ability to move from raw data through preparation and modelling to a business-facing dashboard and recommendations. It is intended to demonstrate practical junior data analyst skills rather than only dashboard design.
