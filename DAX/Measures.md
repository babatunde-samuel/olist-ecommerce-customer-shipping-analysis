# DAX Measures Documentation

The Power BI report contains measures used to produce the KPI cards and analytical visuals.

## Measures visible in the report

### Total Revenue
Used for the total revenue KPI and revenue-based visualisations.

### Total Orders
Used for the total orders KPI.

### Average Delivery Days
Used to monitor the average delivery time.

### Average Freight
Used to monitor average freight cost.

### Monthly Revenue
Used in the monthly revenue trend.

### Product Revenue
Used to rank product categories by revenue.

### Seller Revenue
Used to rank sellers by revenue.

### Seller Label
Used to present sellers with a shorter, dashboard-friendly label.

## Note

The exact DAX expressions should be copied from the Power BI model into this file before publishing the repository. This keeps the portfolio documentation consistent with the final PBIX rather than recreating formulas from memory.
